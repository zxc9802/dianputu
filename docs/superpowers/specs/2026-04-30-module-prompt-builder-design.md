# 模块化生图提示词设计

## 目标

生图接口必须根据用户确认或修改后的最新商品信息，在后端为每个固定模块生成隐藏提示词。提示词不在前端展示，但必须传给图片生成模型。

## 设计

- 新增后端提示词构建器，负责把 `product_info`、风格配置和模块配置组装成完整提示词。
- 每张图都包含统一的产品生成 brief：产品名称、品类、规格、核心卖点、功效、成分、人群、使用方法、权威资料、效果数据。
- 每张图都包含固定模块结构约束：只能生成当前模块，不新增一级模块，不混入其他模块职责。
- 权威资质模块必须写清楚权威信息是什么，例如实验室研发、检测报告、专研配方理念，以及资料来源类型。
- 效果对比模块必须写清楚每条效果数据，例如指标、数值、来源类型；如果是 AI 补全或示意型数据，提示词必须要求画面避免绝对化医疗表达。
- 用户在前端补充或修改字段后，`/api/projects/generate` 接收的最新 `product_info` 会重新参与提示词构建。

## 测试

- 单元测试提示词构建器：验证模块结构、权威信息、效果数据、用户修改字段都会进入隐藏提示词。
- 路由生成测试：验证 `generate_detail_images()` 调用图片模型时使用新的模块化提示词。
