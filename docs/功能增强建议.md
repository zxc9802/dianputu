# 功能增强建议

> 版本：V1.1
> 状态：待排期
> 日期：2026-05-07
> 目标：在 MVP 基础上提升运营日常使用体验

---

## 一、单张图片微调指令

### 1.1 痛点

生成的图整体 80% 满意，但某个细节想调整（文字大小、背景颜色、产品位置等），当前只能整张重新生成，结果不可控。

### 1.2 方案

在预览页每张已生成图片下方加一个**微调输入框**，运营用自然语言描述修改意见，后端将原图 + 微调指令一起发给图片模型做编辑，返回修改后的图片。

微调指令示例：
- 「文字放大 30%」
- 「背景颜色改成更深的绿色」
- 「把产品移到画面左侧」
- 「去掉右下角的水滴装饰」

### 1.3 交互原型

```
┌──────────────────────────┐
│                          │
│       生成的图片           │
│                          │
├──────────────────────────┤
│ [输入微调指令...]   [微调]  │
│ 重新生成 | 下载            │
└──────────────────────────┘
```

### 1.4 核心价值

把「80 分初稿 → 90 分可用图」的最后一步也交给 AI，运营不需要打开 PS。

## 二、多版本 A/B 生成 + 左右对比

### 2.1 痛点

运营经常需要对比多个版本，当前每次重新生成直接覆盖旧图，无法对比选择。

### 2.2 方案

- 每个模块最多保留 **3 个历史版本**
- 重新生成时旧图不覆盖，push 到版本列表
- 预览页加**版本切换器**，可在不同版本间切换查看
- 导出长图时使用当前选中的版本

### 2.3 交互原型

```
┌──────────────────────────┐
│                          │
│      当前选中版本图片       │
│                          │
├──────────────────────────┤
│ [v1 ✅] [v2] [v3]        │
│ 再生成一版 | 选为正式版     │
└──────────────────────────┘
```

### 2.4 核心价值

符合运营「多比几版挑最好的」的自然工作习惯，减少反复从零生成的挫败感。

## 三、从产品图自动提取品牌色 → 智能推荐风格

### 3.1 痛点

当前只有 3 套固定风格，运营不确定哪个最适合当前产品。

### 3.2 方案

上传产品主图后，后端用图像处理提取产品包装的**前 3 个主色调**，然后：

1. 计算与 3 套风格主色的色差（CIE Delta E）
2. 推荐最接近的风格，在风格卡片上显示「✨ 根据产品配色推荐」标签
3. 展示提取到的品牌色色块，供运营参考

### 3.3 交互原型

```
风格选择页：

  提取到的产品主色：🟢 #2D8B4E  🟤 #8B6F47  ⬜ #F5F0E8

  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │ 绿色修护风 │  │ 蓝色补水风 │  │ 金色抗老风 │
  │ ✨ AI推荐  │  │          │  │          │
  │  [已选择]  │  │ [选择此风格]│ │ [选择此风格]│
  └──────────┘  └──────────┘  └──────────┘
```

### 3.4 核心价值

小改动大效果，让风格选择从「凭感觉」变成「有依据」。

## 四、多平台尺寸适配一键切换

### 4.1 痛点

不同电商平台对主图和详情图的尺寸要求不同，运营需要手动调整或找设计师裁剪。

### 4.2 方案

在生成前加一个「目标平台」选择器，自动调整图片生成的尺寸参数。

| 平台 | 主图尺寸 | 详情图宽度 |
|------|---------|-----------|
| 淘宝/天猫 | 800×800 | 750px |
| 京东 | 800×800 | 750px |
| 抖音电商 | 600×600 | 750px |
| 拼多多 | 750×750 | 750px |
| 小红书 | 1080×1080 / 3:4 | 1080px |

导出时可选择同时输出多个平台的尺寸包。

### 4.3 核心价值

一次生成、多平台复用，减少重复劳动。

## 五、项目模板

### 5.1 痛点

同品类产品的详情页结构高度相似，运营每次都要重新选模块、选风格。

### 5.2 方案

- 生成满意的一套图后，支持「保存为模板」
- 模板保存的内容：启用的模块列表 + 模块顺序 + 风格 + 品类
- 下次新建项目时可选择「从模板创建」，一键导入所有配置，只需要换产品资料
- 内置 2-3 个「官方推荐模板」作为起点

### 5.3 交互原型

```
新建项目时：

  ┌ 从空白开始 ┐  ┌ 精华类模板 ┐  ┌ 面霜类模板 ┐  ┌ 我的模板A ┐
  │ 手动选择    │  │ 7模块+绿色  │  │ 6模块+金色  │  │ 5模块+蓝色 │
  └────────────┘  └────────────┘  └────────────┘  └───────────┘
```

### 5.4 核心价值

同品类产品复用率高，大幅减少重复配置时间。

## 六、单张图片 AI 质量自检

### 6.1 痛点

AI 生成的图片偶尔会出现乱码文字、产品变形、不可读文字等问题，运营需要逐张肉眼检查。

### 6.2 方案

每张图生成后，自动调用文字分析模型做一轮质量检查，检查维度：

- 是否有乱码 / 不可读文字
- 产品瓶身是否变形 / 截断
- 文字是否遮挡关键视觉
- 整体构图是否合理
- 是否有明显 AI 生成痕迹

检查结果以标签形式显示在图片上：
- ✅ 质量通过
- ⚠️ 建议重新生成（附原因）

### 6.3 核心价值

把人工质检交给 AI，减少肉眼检查的工作量和遗漏风险。

## 七、文案话术优化建议

### 7.1 痛点

运营填写的卖点话术可能不够吸引人或不够精练，但不知道怎么改更好。

### 7.2 方案

AI 解析完产品信息后，在确认页额外给出一段「文案优化建议」卡片：

- 当前卖点表达是否够吸引人
- 是否有更精练的表达方式
- 核心卖点的排序建议（高转化卖点前置）
- 针对目标人群的话术调整

运营可以一键采纳建议，也可以忽略。

### 7.3 核心价值

让不擅长文案的运营也能写出高转化卖点。

## 八、一键复制项目

### 8.1 痛点

运营做完一个产品后，想做同系列的另一个产品。当前没有「复制」入口，所有配置需要重新来。

### 8.2 方案

在项目顶部加「复制项目」按钮：
- 复制所有风格、模块、品类配置
- 清空产品信息和已生成图片
- 运营只需要替换产品资料和产品图即可

### 8.3 核心价值

同系列产品快速起步，30 秒完成配置。

## 优先级排序

| 优先级 | 功能 | 理由 |
|--------|------|------|
| ⭐⭐⭐ | 单张图片微调指令 | 直接解决「80→90 分」核心痛点 |
| ⭐⭐⭐ | 多版本 A/B 对比 | 运营最常用的工作方式 |
| ⭐⭐ | 项目模板 | 同品类复用率高，大幅提效 |
| ⭐⭐ | 品牌色提取 + 智能推荐 | 小改动大效果 |
| ⭐⭐ | 生成质量自检 | 减少人工检查，提升信任度 |
| ⭐ | 多平台尺寸适配 | 配置化改动，优先级看业务需求 |
| ⭐ | 一键复制项目 | 实用但频率不高 |
| ⭐ | 文案话术优化 | 增值功能 |
