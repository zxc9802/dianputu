# 店铺主图生成方案

> 版本：V1  
> 状态：待落地  
> 日期：2026-05-10  
> 适用范围：店铺主图生成、活动主图生成、主图 Prompt 优化、点击率导向视觉验收

---

## 一、优化目标

店铺主图和详情页的生成逻辑不同。

详情页负责完整说服，主图负责在货架里抢点击。用户在商品列表里只会快速扫一眼，所以主图必须做到：产品清楚、卖点直接、视觉抓人、信息短促。

本方案目标：

- 提升主图点击率导向的视觉冲击力。
- 避免多张主图都变成“产品居中 + 环绕文字 + 柔和背景”的同质化模板。
- 保持 5 张主图之间的分工清晰。
- 让每张主图只完成一个核心任务。
- 产品包装、卖点、成分、效果、使用场景都能形成连续但不重复的货架表达。

主图核心公式：

> 产品大 + 卖点狠 + 证据短 + 视觉亮 + 信息少

---

## 二、主图整体结构

当前店铺主图建议继续按照现有结构生成：

1. 白底图
2. 首图 / 核心卖点图
3. 次图-成分
4. 次图-效果
5. 次图-使用场景

每张主图的任务不同：

| 主图 | 页面任务 |
| --- | --- |
| 白底图 | 平台合规、商品识别、看清包装 |
| 首图 / 核心卖点图 | 抢点击，让用户一眼知道卖什么、解决什么问题 |
| 次图-成分 | 快速解释配方亮点 |
| 次图-效果 | 展示使用收益和变化感 |
| 次图-使用场景 | 建立代入感，让用户想象自己会怎么用 |

主图不是详情页，不能讲太多。每张图只传递一个主要信息。

## 三、模块生成方案

### 3.1 白底图

页面任务：用于平台合规和商品识别，让用户清楚看到真实产品。

生成方法：

- 背景必须为纯白色。
- 产品居中完整展示。
- 保留真实包装、Logo、标签、颜色、瓶身比例和包装图案。
- 产品边缘干净，允许极淡自然投影。
- 不改变产品外观，不重绘包装。

禁止出现：

- 人物
- 水滴
- 植物
- 光效
- 促销贴纸
- 卖点文案
- 渐变背景
- 产品标签被擦除或变成空白

验收标准：

- 一眼能看清产品包装。
- 背景干净纯白。
- 产品没有变形、换瓶、改字。
- 符合电商平台白底图基础要求。

---

### 3.2 首图 / 核心卖点图

页面任务：决定点击率，是 5 张主图里最重要的一张。

生成方法：

- 产品必须作为最大视觉主体，占画面 45%-55%。
- 一个大标题打核心卖点，标题要短、狠、直接。
- 搭配 2-4 个小标签补充利益点。
- 可以加入规格、适用人群、促销利益点，但不能挤满画面。
- 背景要饱满，有商业摄影光影，不要大面积空白。
- 产品要有强轮廓光、反光、体积感和质感。
- 构图要像货架爆款图，而不是品牌氛围海报。

推荐标题方向：

- `干皮急救 一抹水润`
- `卡粉起皮？先稳住屏障`
- `熬夜暗沉脸 也能透亮服帖`
- `敏感肌也能安心用`

推荐视觉元素：

- 产品大图
- 镜面台
- 亚克力台
- 精华液滴
- 水光纹理
- 产品背后柔光
- 少量高亮标签

禁止出现：

- 成分表
- 使用步骤
- 大段说明文字
- 产品太小
- 背景太空
- 卖点不清楚
- 只追求好看但看不出卖什么

验收标准：

- 0.3 秒内能知道核心卖点。
- 产品是最抢眼主体。
- 标题比其他文字明显更大。
- 小标签不超过 4 个。
- 画面有点击欲，不像普通陈列图。

---

### 3.3 次图-成分

页面任务：快速解释配方亮点，让用户知道产品为什么值得信。

次图-成分不是详情页成分页，不能讲太细。它只负责用很短的信息告诉用户：这个产品有几个值得看的核心成分。

生成方法：

- 主视觉是核心成分微距，不是产品大图。
- 产品可以缩小放在角落或侧边。
- 最多展示 2-3 个核心成分。
- 每个成分只写一句作用短标签。
- 使用高级原料质感，例如水滴、凝露、植萃、分子线、透明精华液、原料切面。
- 构图建议使用左右分栏或成分卡片布局。

推荐结构：

- 左侧：成分微距大片
- 右侧：成分名 + 短作用标签
- 角落：产品小图

推荐表达：

- `透明质酸：帮助提升水润肤感`
- `神经酰胺：帮助维持屏障舒适`
- `积雪草：帮助舒缓干燥不适`

禁止出现：

- 完整成分表
- 超过 3 个核心成分
- 效果数据百分比
- 使用步骤
- 人物使用场景
- 产品居中环绕文字的首图构图
- 药品疗效或治疗表达

验收标准：

- 一眼知道这是成分图。
- 成分是主视觉，不是产品瓶身。
- 信息短，不像百科说明。
- 和首图构图明显不同。

---

### 3.4 次图-效果

页面任务：让用户看到使用收益和结果感。

生成方法：

- 使用局部前后对比，面积建议占画面 25%-35%。
- 对比区域不能占满整张图，必须同时出现产品和标题。
- 有真实数据时放大数字；没有真实数据时使用体验型表达。
- 使用前可以表现干燥、粗糙、暗沉、卡粉、紧绷。
- 使用后可以表现水润、细腻、服帖、光泽。
- 数据或标签要短，不能做成枯燥 PPT。

推荐表达：

- `妆面更服帖`
- `水润感提升`
- `干燥紧绷感减少`
- `肌肤看起来更细腻`

推荐视觉元素：

- 局部肌肤对比卡
- 简洁进度条
- 大数字标签
- 产品小角度陈列
- 柔和美妆光

禁止出现：

- 编造百分比
- 医疗治疗式前后对比
- 夸张换脸效果
- 只有漂亮脸，没有变化证据
- 成分详情列表
- 使用步骤

验收标准：

- 一眼看出这是效果图。
- 有明确变化或收益表达。
- 产品仍然清晰可见。
- 画面可信，不像医疗广告。

---

### 3.5 次图-使用场景

页面任务：建立代入感，让用户想象自己在什么场景下会用这个产品。

生成方法：

- 主视觉使用真人使用动作或生活护理场景。
- 场景可以是梳妆台、浴室、镜前、晨间护肤、妆前护理。
- 光线使用自然窗光、柔和生活光，真实但高级。
- 产品必须清楚出现，不能被手、道具或人物遮挡。
- 人物表情自然，避免 AI 网红感和过度精修。
- 文案强调适用人群、使用时机或使用体验。

推荐表达：

- `晨间上妆前`
- `换季干燥时`
- `熬夜后护理`
- `妆前打底更服帖`

推荐视觉元素：

- 手部取用
- 镜前涂抹
- 梳妆台陈列
- 浴室台面
- 自然窗光
- 干净毛巾或少量护肤道具

禁止出现：

- 数据图表
- 成分列表
- 复杂说明文字
- 凌乱居家背景
- 随意自拍感
- 人物遮挡产品
- 夸张摆拍表情

验收标准：

- 一眼知道产品怎么用、什么时候用。
- 场景真实，有代入感。
- 产品清楚可见。
- 人物自然，不像 AI 精修大片。

---

## 四、统一视觉规则

5 张主图需要统一，但不能长得一样。

统一内容：

- 产品包装质感
- 字体层级
- 标签样式
- 光影品质
- 色彩系统
- 图标语言
- 材质质感

必须差异化的内容：

- 构图
- 主视觉
- 信息重点
- 产品占比
- 背景类型
- 情绪强度

推荐分配：

| 主图 | 产品占比 | 主视觉 | 构图方向 |
| --- | --- | --- | --- |
| 白底图 | 70%-85% | 产品本体 | 居中纯白 |
| 首图 | 45%-55% | 产品大图 + 核心卖点 | 饱满商业构图 |
| 次图-成分 | 10%-25% | 成分微距 | 左右分栏或卡片 |
| 次图-效果 | 20%-35% | 局部效果对比 | 产品 + 对比卡 + 数据标签 |
| 次图-使用场景 | 15%-30% | 真人使用场景 | 生活方式摄影 |

## 五、活动主图补充规则

活动主图可以沿用主图结构，但要增加促销转化元素。

活动主图生成原则：

- 产品仍然是主体，促销元素不能压过产品。
- 促销信息必须来自用户填写内容，不能编造价格、折扣、日期、赠品或满减门槛。
- 促销标签建议控制在 1-3 个。
- 活动氛围可以更强，但画面不能变成促销贴纸堆叠。

适合加入的元素：

- 优惠券样式标签
- 限时角标
- 买赠标签
- 满减标签
- 活动色块
- 节日光效

禁止出现：

- 编造折扣
- 编造活动时间
- 编造价格
- 促销元素遮挡产品
- 整张图只剩活动氛围，看不清产品

## 六、Prompt 落地字段

后续主图模块 Prompt 建议增加以下字段：

```text
主图任务：
主视觉主体：
产品占比：
核心标题：
辅助标签数量：
构图方向：
光影方向：
必须出现：
禁止出现：
合规边界：
```

示例：首图 / 核心卖点图

```text
主图任务：在电商货架中抢点击，让用户 0.3 秒内知道产品核心卖点。
主视觉主体：产品大图 + 一个强卖点标题。
产品占比：45%-55%。
核心标题：使用前 1 个核心卖点，短促有力。
辅助标签数量：2-4 个。
构图方向：饱满商业构图，产品居中或居中偏左，背景有镜面台和商业高光。
光影方向：强轮廓光、柔和主光、产品反光清晰。
必须出现：产品、核心标题、少量卖点标签。
禁止出现：成分表、使用步骤、大段文字、产品太小、背景过空。
合规边界：不使用绝对化、医疗化、虚假数据或未经确认的权威背书。
```

示例：次图-成分

```text
主图任务：快速展示 2-3 个核心成分，让用户理解配方亮点。
主视觉主体：成分微距和原料质感。
产品占比：10%-25%，可放角落辅助。
核心标题：突出核心成分体系。
辅助标签数量：每个成分 1 个短作用标签。
构图方向：左右分栏或成分卡片布局。
光影方向：清透微距光、凝露高光、原料质感清晰。
必须出现：核心成分名、短作用标签、成分微距。
禁止出现：完整成分表、效果数据、使用步骤、人物场景。
合规边界：成分作用表达温和，不写治疗、治愈或药品疗效。
```

## 七、执行优先级

### P0：优先优化

1. 首图 / 核心卖点图
2. 次图-效果
3. 次图-成分

原因：这三张最影响点击率、信任感和购买兴趣。

### P1：第二批优化

1. 次图-使用场景
2. 活动首图
3. 活动次图-效果

原因：这些图负责增强代入感和促销转化。

### P2：稳定合规

1. 白底图
2. 活动白底图

原因：白底图主要负责平台合规和商品识别，重点是稳定保真。

---

## 八、验收标准

生成结果需要满足以下标准：

- 5 张主图一眼能看出各自任务，不会像同一模板换文字。
- 白底图产品真实、完整、纯白、无装饰。
- 首图产品足够大，卖点足够明确，具备货架点击力。
- 成分图以成分微距为主视觉，不做完整成分表。
- 效果图有变化或收益表达，不编造数据。
- 使用场景图真实自然，产品清晰可见。
- 活动主图有促销氛围，但不遮挡产品，不编造优惠。
- 全套主图视觉统一，但构图和主视觉明显差异化。
- 不出现医疗化、治疗化、绝对化表达。
- 不出现乱码、水印、侵权品牌标识或虚假权威背书。

---

## 九、总结

店铺主图的核心不是完整讲解产品，而是在货架中快速抓住用户。

主图要比详情页更短、更狠、更重产品占比和点击率。每张图只完成一个任务：白底图看清商品，首图抢点击，成分图讲配方亮点，效果图证明收益，场景图建立代入感。

最终目标是让 5 张主图形成一套清晰的点击链路：先看清产品，再被卖点吸引，再相信成分和效果，最后想象自己使用。
