# 详情主页优化方案

> 版本：V1  
> 状态：待落地  
> 日期：2026-05-10  
> 适用范围：商品详情页模块图片生成、模块 Prompt 优化、生成质量验收

---

## 一、优化目标

当前详情页结构本身不需要推翻，问题主要在于生成方法还偏“说明型图片”：画面温和、冲击力不足、痛点不够直观、成分解释不够有说服力、不同模块之间的销售推进感不强。

本次优化目标是：在保留现有详情页结构的基础上，把每个模块从“把信息画出来”升级为“按电商转化逻辑说服用户”。

重点提升：

- 痛点更直观，让用户感觉“这说的就是我”。
- 卖点更醒目，第一眼知道产品解决什么问题。
- 产品更有存在感，不被背景和装饰淹没。
- 权威页更像真实研发/检测场景，而不是证书堆叠。
- 效果页更有证据感，能看到使用前后的变化。
- 成分页从“成分罗列”升级为“配方机制解释”。
- 整套详情页有连续的销售推进感。

---

## 二、整体原则

详情页继续按照当前固定结构生成，不新增一级模块，不改变现有模块顺序逻辑。

推荐详情页结构：

1. 详情首图
2. 权威资质展示
3. 痛点场景
4. 效果对比
5. 竞品对比
6. 成分总览
7. 成分 1 讲解
8. 成分 2 讲解
9. 成分 3 讲解
10. 使用方法

每张图生成前都必须明确四件事：

- 页面任务：这一页负责抓眼球、建立信任、放大痛点、证明效果，还是解释成分。
- 主视觉：人物、产品、实验室、成分微距、前后对比，不能混乱。
- 用户看完要相信什么：例如“我有这个痛点”“这个产品有依据”“这个成分能解释卖点”。
- 禁止出现什么：避免把其他模块内容混入当前画面。

核心生成规则：

> 每张图必须有一个视觉矛盾：问题 vs 解决、普通 vs 专业、使用前 vs 使用后、单一护理 vs 成分体系。

## 三、模块优化方案

### 3.1 详情首图

页面任务：让用户第一眼知道这个产品解决什么问题，并愿意继续往下看。

生成方法：

- 产品作为主视觉，占画面 35%-50%。
- 主标题短、狠、直接，只打一个核心卖点。
- 搭配 2-4 个卖点标签，辅助解释产品价值。
- 背景使用商业摄影光影，例如镜面台、亚克力、水光、精华液滴、实验室冷光。
- 画面要有“爆款详情首屏”的饱满感，不能像品牌氛围海报。

推荐标题方向：

- `干皮急救 一抹水润`
- `卡粉起皮？先稳住屏障`
- `熬夜暗沉脸 也能透亮服帖`

禁止出现：

- 长段说明文字
- 成分表
- 使用步骤
- 权威证书
- 产品过小或被背景淹没

---

### 3.2 权威资质展示

页面任务：建立信任感，让用户觉得产品不是随便做的。

生成方法：

- 主视觉使用实验室、研究员、仪器、试管、检测台、研发记录等元素。
- 光影使用冷白、银色金属反光、蓝色科技光或少量红色数据屏。
- 报告、证书、文件只能作为局部辅助物件，不超过画面 25%。
- 报告文字必须模糊或泛化，不能编造真实报告编号、样本编号、机构编号。
- 产品可以出现在前景或侧边，和实验场景形成关联。

推荐短标签：

- `配方专研`
- `品质检测`
- `安心品控`
- `成分可信`

禁止出现：

- 编造真实机构背书
- 编造专利数量、临床数据、检测编号
- 满屏证书或资质墙
- 医院广告感
- 半透明 UI 报告面板取代真实纸质文件

---

### 3.3 痛点场景

页面任务：让用户产生强烈代入感，觉得“这就是我的问题”。

这是当前最需要重点加强的模块。

生成方法：

- 人物要有明显困扰表情，例如皱眉、照镜子、摸脸、上妆卡粉。
- 痛点必须可视化，例如起皮、卡粉、粗糙、紧绷、暗沉、泛红。
- 增加局部放大镜、肌肤纹理特写或问题区域标注。
- 使用红色警示标签点名问题。
- 光线使用冷光、侧光或镜前光，把皮肤纹理和问题区域打出来。
- 背景可以是镜前、梳妆台、浴室，不要做成过于漂亮的护肤氛围照。

推荐版式：

- 上方：强痛点标题
- 中间：镜前人物 + 局部肌肤放大
- 下方：3-4 个痛点标签

推荐标题方向：

- `补水没用？越补越干`
- `一上妆就卡粉起皮`
- `脸干到发紧发痒`

推荐痛点标签：

- `卡粉起皮`
- `干到发紧`
- `泛红刺痛`
- `暗沉粗糙`

禁止出现：

- 人物表情过于平静
- 皮肤问题完全看不出来
- 只拍漂亮氛围
- 过度丑化皮肤
- 医疗化严重症状
- 提前展示效果数据或权威报告

---

### 3.4 效果对比

页面任务：让用户看到变化，并相信产品有使用收益。

生成方法：

- 必须出现使用前/使用后局部对比。
- 对比区域建议占画面 30%-45%，不要整张图只有左右对比。
- 画面同时包含产品、标题、局部对比卡片、功效说明或数据标签。
- 使用前表现干燥、粗糙、暗沉、卡粉、纹理明显。
- 使用后表现水润、细腻、服帖、光泽更自然。
- 有真实数据时放大数字；没有真实数据时使用体验型表达，不编造百分比。

推荐表达：

- `水润感提升`
- `妆面更服帖`
- `肌肤更细腻`
- `干燥紧绷感减少`

禁止出现：

- 编造百分比或测试数据
- 医疗治疗式前后对比
- 夸张到不可信的换脸效果
- 整张图只有左右两块对比，没有产品和卖点承接

---

### 3.5 竞品对比

页面任务：让用户知道为什么选择本产品，而不是普通同类产品。

生成方法：

- 左侧展示普通同类产品的常见不足。
- 右侧展示本产品的差异化优势。
- 左侧视觉偏灰、暗、干、粗糙；右侧视觉偏亮、润、干净。
- 对比维度控制在 3-5 个。
- 不指名真实竞品品牌，只表达“普通同类产品”。

推荐对比维度：

- `补水后仍干` vs `水润更持久`
- `上妆易卡粉` vs `妆面更服帖`
- `厚重黏腻` vs `清爽好吸收`
- `只补水不修护` vs `补水 + 屏障护理`

禁止出现：

- 指名真实竞品品牌
- 恶意攻击竞品
- 表格太密
- 文案过长
- 只做普通表格，没有视觉反差

---

### 3.6 成分总览

页面任务：建立配方体系，让用户先理解产品用了哪些核心成分方向。

成分总览只做“体系介绍”，不展开单个成分的长篇解释。

生成方法：

- 最多展示 3 个核心成分。
- 每个成分对应一个护理方向，例如补水、修护、舒缓。
- 产品可以小比例出现在角落，作为配方来源提示。
- 主视觉使用成分浮岛、胶囊卡、分子线、精华液流动、微距原料。
- 文案保持短句，避免完整成分表。

推荐标题：

- `3 重核心成分 协同护理`
- `补水 + 修护 + 舒缓`
- `从干燥、脆弱、粗糙三个方向入手`

禁止出现：

- 完整成分表
- 超过 3 个核心成分
- 长篇科普
- 多个成分作用混在一起
- 药品疗效或治疗表达

---

### 3.7 成分 1/2/3 讲解

页面任务：逐个讲清楚单个成分为什么有用。

统一规则：

- 一张图只出现一个成分。
- 一个成分只对应一个主要作用。
- 不出现其他成分名称。
- 不出现完整成分表。
- 不出现效果数据。
- 不出现使用步骤。
- 不医疗化、不治疗化。

每张单成分页固定结构：

- 大标题：成分名
- 副标题：一句消费者能理解的作用
- 对应痛点：这个成分解决什么问题
- 主视觉：成分微距、原料质感或机制视觉
- 产品：小比例辅助出现

示例：

成分 1：透明质酸

- 作用：帮助提升水润肤感
- 对应痛点：干燥紧绷
- 视觉方向：透明水滴、凝露、肌肤水分纹理
- 页面重点：水润感、充盈感、清透感

成分 2：神经酰胺

- 作用：帮助维持屏障舒适
- 对应痛点：换季脆弱、干燥不适
- 视觉方向：仿生屏障膜、柔和包裹感、脂质层结构
- 页面重点：屏障、防护、稳定

成分 3：积雪草

- 作用：帮助舒缓干燥不适
- 对应痛点：泛红、紧绷、敏感不适
- 视觉方向：绿色植萃、晨露、舒缓冷光
- 页面重点：舒缓、安心、温和

三张单成分页必须统一风格，但构图不能复制粘贴：

- 成分 1 可做微距质地图。
- 成分 2 可做机制结构图。
- 成分 3 可做舒缓场景或植萃质地图。

---

### 3.8 使用方法

页面任务：降低使用门槛，让用户觉得简单、清楚、容易执行。

生成方法：

- 控制在 3-4 步。
- 每一步配真实动作，例如取量、点涂、推开、按摩吸收。
- 场景使用干净浴室、梳妆台、自然窗光。
- 产品必须清楚出现。
- 图标、编号和步骤文字要清晰。

推荐步骤：

1. 洁面后取适量
2. 点涂于面部
3. 轻柔推开
4. 按摩至吸收

禁止出现：

- 说明书式密集文字
- 步骤过多
- 产品被手或道具遮挡
- 场景杂乱
- 使用动作不真实

---

## 四、统一视觉规则

整套详情页要统一，但不能每张都长一样。

统一的内容：

- 字体层级
- 产品质感
- 光影品质
- 标签样式
- 色彩系统
- 图标语言
- 材质表达

需要变化的内容：

- 构图
- 主视觉
- 情绪强度
- 光影方向
- 信息密度
- 画面节奏

推荐光影分配：

| 模块 | 光影方向 |
| --- | --- |
| 详情首图 | 商业高光、产品强轮廓光 |
| 权威资质展示 | 冷白实验室光、银色金属反光 |
| 痛点场景 | 冷光、侧光、镜前光，突出问题纹理 |
| 效果对比 | 柔和美妆光 + 局部对比光 |
| 竞品对比 | 左暗右亮，形成视觉胜负 |
| 成分总览 | 微距高光、精华流动光 |
| 成分 1/2/3 | 单成分专属微距光或机制光 |
| 使用方法 | 自然窗光、真实生活护理感 |

## 五、Prompt 落地字段

后续每个模块 Prompt 建议增加以下字段，保证图片生成稳定：

```text
页面任务：
主视觉主体：
核心文案层级：
光影方向：
情绪强度：
产品占比：
必须出现：
禁止出现：
合规边界：
```

示例：

```text
页面任务：放大目标用户的干燥卡粉痛点，让用户产生代入感。
主视觉主体：镜前人物 + 局部肌肤放大镜。
核心文案层级：1 个强痛点标题 + 3 个痛点标签。
光影方向：冷色镜前光、侧光突出皮肤纹理。
情绪强度：强冲击，但不制造严重医学症状。
产品占比：本页可不作为最大主体，允许小比例出现在角落。
必须出现：困扰表情、局部问题纹理、红色痛点标签。
禁止出现：效果数据、权威报告、成分表、使用步骤。
合规边界：不出现治疗、治愈、医学疾病、严重皮肤损伤表达。
```

## 六、执行优先级

### P0：优先优化

1. 痛点场景
2. 效果对比
3. 权威资质展示

原因：这三张最直接影响视觉冲击力、信任感和转化意愿。

### P1：第二批优化

1. 详情首图
2. 成分总览
3. 成分 1/2/3 讲解

原因：这些模块负责把卖点讲完整，并解释产品为什么值得买。

### P2：第三批优化

1. 竞品对比
2. 使用方法

原因：这两张主要负责补充说服和降低使用顾虑。

---

## 七、验收标准

生成结果需要满足以下标准：

- 每个模块一眼能看出页面任务，不会混成同一种模板。
- 痛点页能清楚看到用户困扰和具体问题。
- 效果页有局部对比和清晰收益表达。
- 权威页像真实研发/检测场景，不像证书拼贴。
- 成分总览只讲体系，不展开长篇说明。
- 成分 1/2/3 每张只讲一个成分，且构图有差异。
- 使用方法页步骤清楚，场景干净，产品可见。
- 全套详情页视觉统一，但每张图有不同主视觉和节奏。
- 不编造真实机构、检测编号、专利数量、百分比数据。
- 不出现医疗化、治疗化、绝对化表达。

---

## 八、总结

本方案不改变现有详情页结构，只升级每个模块的生成方法。

最终目标是让详情页从“说明型图片”升级为“销售型图片”：先抓住注意力，再放大痛点，再建立信任，再证明效果，最后用成分机制和使用方法完成购买说服。
