# 详情页提示词减法优化方案

> 版本：V1  
> 状态：待落地  
> 日期：2026-05-14  
> 适用范围：商品详情页模块图片生成、Prompt 约束补充、视觉验收

---

## 一、问题背景

当前详情页 Prompt 已经具备模块任务、主视觉、构图差异化和合规边界，但图片模型在生成时仍会主动补充一些“看起来高级”的装饰元素，例如：

- 角落叶子、悬挂叶子、前景虚焦叶片
- 背景植物影、窗影、墙面投影
- 花草线稿、枝条纹理、装饰性水滴
- 光斑、光束、渐变阴影、边角点缀
- 与当前页面任务无关的图标、卡片和纹理

这些元素的问题不在于“植物、光影、水滴本身不能出现”，而在于它们没有承担当前页面的信息任务，只是在填充留白，导致画面变杂，削弱美工希望的干净感。

本方案不推翻现有提示词，只在现有模块 Prompt 末尾增加“视觉减法补充规则”，用于约束模型不要自作主张添加无关装饰。

---

## 二、融合原则

### 2.1 不替换现有提示词

现有提示词中已经定义了页面任务、主视觉、构图、光影、合规和模块禁区，本方案只作为补充约束使用。

推荐拼接顺序：

```text
原来的页面任务
+
原来的主视觉/构图要求
+
原来的模块内容要求
+
原来的合规要求
+
【视觉减法补充规则】
```

### 2.2 不误杀必要主视觉

不要简单写成“禁止植物、禁止水滴、禁止光影”，否则会和现有成分页、效果页、首图提示词冲突。

正确逻辑是：

```text
允许当前模块必需的主视觉元素。
禁止与当前模块任务无关的装饰性元素。
```

例如：

- 成分页可以出现当前成分对应的原料，但不能额外添加角落叶子和背景叶影。
- 效果页可以出现水润肌肤质感，但不能额外添加无关水滴和光斑。
- 使用方法页可以出现自然窗光，但不能出现装饰性窗影和植物摆件。
- 产品信息页只展示信息，不需要任何氛围装饰。

### 2.3 放在 Prompt 末尾

视觉减法规则建议放在每个模块 Prompt 的最后。  
原因是前文可能会出现“自然、植萃、清透、光影”等风格词，如果减法规则放太前面，模型后续仍可能被风格词带偏。

---

## 三、全局补充提示词

以下内容可作为所有详情页模块的统一追加 Prompt。

```text
【视觉减法补充规则】
以下规则不改变当前模块的页面任务、主视觉、构图方向和必要元素，只用于删除无关装饰。

本页只允许出现与当前模块内容直接相关的元素。
如果某个元素不能帮助说明当前页的卖点、痛点、效果、成分、步骤、权威或产品信息，就不要生成。

允许出现：
- 当前模块明确需要的主视觉元素。
- 当前模块必要的产品、人物、原料、对比、实验室、步骤、表格或信息标签。
- 与主视觉直接相关的少量真实材质和光影。

禁止出现：
装饰性植物、角落叶子、悬挂叶子、虚焦前景叶片、背景叶影、植物投影、窗户投影、墙面光斑、无关水滴、花草线稿、枝条纹理、装饰光束、漂浮图形、边角点缀、无意义图标、填充留白的纹理或阴影。

留白必须保持干净。
不要为了让画面更丰富而添加任何无关装饰。
```

## 四、各模块融合提示词

### 4.1 详情首图

现有方向：产品主视觉、核心卖点、商业摄影光影。

追加约束：

```text
【详情首图减法约束】
可以出现商业摄影台面、柔和光影和产品质感，但所有辅助元素必须服务于产品和核心卖点。
不要添加与核心卖点无关的植物、叶影、花草、虚焦前景、角落装饰、装饰光斑或背景花纹。
产品和主标题必须是画面第一视觉焦点。
留白区域保持干净，不要用装饰元素填满。
```

### 4.2 权威资质展示

现有方向：实验室、研究员、仪器、局部报告，建立信任感。

追加约束：

```text
【权威页减法约束】
只保留与研发、检测、品控相关的实验室元素。
可以出现研究员、仪器、试管、检测台、局部纸质报告和少量泛化信任标签。
不要添加植物、花草、装饰性光斑、背景纹理、悬浮 UI 面板、科技感装饰线条或无关图标。
报告和证书只能作为局部辅助，不要堆满画面。
画面保持真实、干净、冷静，不做证书墙和科技海报。
```

### 4.3 痛点场景

现有方向：人物困扰、局部肌肤问题、痛点标签。

追加约束：

```text
【痛点页减法约束】
只保留能说明用户困扰的元素，例如人物表情、镜前动作、局部肌肤问题和痛点标签。
背景可以是镜前、梳妆台或干净浴室，但不能添加无关植物、装饰摆件、花草纹理、窗影、墙面光斑或氛围光束。
不要把画面做成漂亮护肤氛围照。
所有背景元素都必须弱化，不能抢过人物痛点和局部问题。
```

### 4.4 效果对比

现有方向：局部前后对比、产品承接、体验收益表达。

追加约束：

```text
【效果页减法约束】
可以出现肌肤水润质感、局部前后对比、产品辅助图和少量体验型标签。
不要添加与效果证明无关的植物、水滴、光斑、装饰阴影、背景纹理、前景虚化元素或漂浮图形。
如果没有真实数据，不要用装饰性百分比、虚假仪表盘或夸张图表填充画面。
画面重点必须集中在使用前后变化和产品收益。
```

### 4.5 竞品对比

现有方向：普通同类产品 vs 本产品，形成选择理由。

追加约束：

```text
【竞品对比页减法约束】
只保留左右对比结构、3-4 个对比维度、必要产品辅助图和清晰标签。
不要添加植物、花草、背景叶影、复杂纹理、无关图标、装饰性箭头或过多卡片。
对比信息要清楚，不要做成密集表格。
左侧和右侧可以有明暗或质感差异，但不能用大量装饰制造差异。
```

### 4.6 产品大图强化

现有方向：突出产品本身，强化产品质感和记忆点。

追加约束：

```text
【产品大图强化减法约束】
产品必须是唯一主视觉，包装清晰，轮廓干净。
可以出现极简台面、轻微真实阴影和克制商业光影。
不要添加植物、叶影、装饰道具、花草、虚焦前景、复杂光斑、边角纹理或填充留白的图案。
画面不要为了丰富而增加道具，重点只放在产品本身。
```

### 4.7 成分总览

现有方向：最多 3 个核心成分，建立配方体系。

追加约束：

```text
【成分总览减法约束】
可以出现 2-3 个核心成分对应的原料、胶囊卡、分子线、精华液流动或成分浮岛。
所有原料元素必须对应当前展示的核心成分。
不要添加额外植物装饰、角落叶子、背景叶影、前景虚焦叶片、花草枝条或无关水滴。
不要用完整成分表、长篇科普或大量小标签填满画面。
留白保持干净，让 2-3 个核心成分成为唯一信息焦点。
```

### 4.8 单成分讲解

现有方向：一张图只讲一个成分，一个成分只对应一个主要作用。

追加约束：

```text
【单成分页减法约束】
本页只能讲一个核心成分，只能出现该成分相关的主视觉原料或机制视觉。
如果主题是芦荟，只允许芦荟主原料作为视觉主体；如果主题是透明质酸，只允许水滴、凝露或补水机制作为主视觉。
不要额外添加顶部叶子、角落叶子、背景叶影、前景虚焦植物、花草枝条、无关水滴或装饰纹理。
产品可以小比例辅助出现，但不能和成分主视觉抢焦点。
留白区域保持干净，不要用植物或阴影填充。
```

### 4.9 使用方法

现有方向：3-4 步，真实动作，干净生活场景。

追加约束：

```text
【使用方法页减法约束】
只保留真实手部动作、产品、步骤编号、短步骤文字和干净使用场景。
可以出现干净浴室、梳妆台、自然窗光，但不能添加无关护肤道具、植物摆件、花草纹理、装饰阴影、复杂背景或氛围光斑。
步骤数量控制在 3-4 步，不要用过多图标、箭头、卡片或说明文字填满画面。
画面要像清晰的使用指导，不像生活方式氛围海报。
```

### 4.10 产品信息

现有方向：产品参数、基础信息、说明书式收口。

追加约束：

```text
【产品信息页减法约束】
只允许出现标题、参数表格、必要分隔线、少量功能图标和产品基础信息。
背景必须干净平整，使用纯白、浅米白或极轻微纸张质感。
不要添加任何装饰背景、植物影子、花草线稿、窗影、墙面投影、边角纹理、光斑、水印、图案或装饰性阴影。
整体像干净的产品说明书页面，不像氛围海报。
```

## 五、推荐落地字段

建议在现有 Prompt 结构中增加一个独立字段：

```text
视觉减法约束：
```

字段位置建议放在：

```text
页面任务：
主视觉主体：
核心文案层级：
光影方向：
情绪强度：
产品占比：
必须出现：
禁止出现：
合规边界：
视觉减法约束：
```

这样可以和现有字段并存，不会破坏原来的模块逻辑。

## 六、代码落地建议

如果落地到 `backend/app/services/prompt_builder.py`，建议分为两层：

1. 全局函数：返回所有详情页通用的视觉减法补充规则。
2. 模块函数：根据 `module_id` 返回当前模块的减法补充规则。

推荐命名：

```text
_global_visual_reduction_rules()
_module_visual_reduction_rules(module)
```

拼接位置建议放在 `build_module_image_prompt` 的末尾，位于现有模块要求、合规要求、文字规则和语言规则之后。

原因：

- 不影响现有页面任务和构图配方。
- 避免前文风格词再次引导模型添加装饰。
- 让减法约束成为最终执行约束。

---

## 七、验收标准

生成结果需要满足以下标准：

- 每张图只保留当前模块需要的信息元素。
- 留白区域干净，不被植物、阴影、纹理、虚焦前景或光斑填充。
- 成分页的植物或原料必须对应当前成分，不能出现额外装饰植物。
- 产品信息页不得出现任何氛围装饰。
- 使用方法页不得出现无关摆件和复杂背景。
- 效果页不得用无关水滴、光斑或虚假图表填充画面。
- 首图和产品大图可以有商业光影，但不能出现抢焦点的装饰物。
- 整套详情页仍保留模块差异，不因为“干净”而全部变成同一种白底模板。

---

## 八、总结

本方案的核心不是让页面变空，而是让每个元素都有信息价值。

判断一个元素能不能留，只看一个问题：

> 它是否帮助用户理解当前页的卖点、痛点、效果、成分、步骤、权威或产品信息？

如果不能，就应该删除。

最终目标是：保留现有详情页的销售推进逻辑，同时让画面更干净、更克制、更符合美工对“少元素、高级感”的要求。
